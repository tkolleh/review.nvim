# Security Policy

## Supported Versions

Only the latest released version is supported with security fixes.

## Reporting a Vulnerability

Please report security issues privately via [GitHub Security Advisories](https://github.com/tkolleh/review.nvim/security/advisories/new)
rather than opening a public issue.

If that isn't available, open a regular issue with minimal detail and a way to reach you privately,
and it will be addressed as quickly as possible.
